### 🚀 Projects

#### 🔹 [net-scout](https://github.com/zoolpher/net-scout)
Modular C++ packet capture/analysis tool built on Npcap/libpcap for Windows. Full Ethernet/IPv4/TCP-UDP header parsing, port-to-protocol mapping, and TLS ClientHello SNI extraction — architected as five clean modules (capture, parser, detector, sni, main) with a CMake build system.

#### 🔹 [binance-lob-capture](https://github.com/zoolpher/binance-lob-capture)
Live orderbook capture engine for Binance over WebSocket. Fixed-point arithmetic, sequence-gap detection, and RFC 4180-compliant CSV writers, wired into a C++ ingestion engine + pybind11 + FastAPI gateway + Redis pub/sub pipeline.

#### 🔹 ESP32 Multiplayer Tic-Tac-Toe
A tic-tac-toe web server running on an ESP32 (WROOM-32). Game logic lives entirely in C++ server-side; the ESP32 hosts its own hotspot, auto-syncs frontend files from GitHub on boot, and caches them to LittleFS. Frontend is plain HTML/CSS/JS, served over WebSocket.

#### 🔹 R.E.D. — Real-Estate Decentralized App
Built at the BIT Mesra Hackathon, where it was selected as a finalist.
